# Security

Store application-security and AI-security reviews here.

Use OWASP ASVS and LLMSVS as verification frameworks, and record:

- scope
- findings
- severity/risk
- evidence
- remediation
- verification after remediation

Prioritize auth/authz, secret handling, API boundaries, SSRF/injection, file handling, dependency risk, AI tool permissions, prompt injection and model/provider trust boundaries.
